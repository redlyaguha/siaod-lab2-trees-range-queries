## Как запустить

Нужен Python 3.10 или новее. Дополнительные библиотеки, установка пакетов и виртуальное окружение не нужны.

Откройте папку `tree_range_lab` в Visual Studio Code. В меню «Терминал» выберите «Создать терминал». Выполните:

```powershell
python main.py
```

Если команда `python` не найдена, попробуйте:

```powershell
py main.py
```

Программа последовательно покажет задания 1–13. Подсчёт 1000 диапазонов в заданиях 8 и 9 занимает несколько секунд. В это время программа работает, даже если ещё ничего нового не напечатала.

Отдельное задание, например анализ датчиков:

```powershell
python main.py 13
```

Повороты дерева:

```powershell
python main.py 7
```

Можно открыть терминал сразу в нужной папке. Из любой другой папки сначала перейдите в проект:

```powershell
cd "C:\Users\admin\Desktop\Универ\СиАОД\Лаба 2 — Деревья и быстрые запросы\tree_range_lab"
python main.py
```

## Как устроен код

- `bst.py`: узел, вставка, поиск, обходы, удаление, высота, баланс-фактор, повороты и вывод дерева.
- `ranges.py`: обычная сумма, префиксные суммы, дерево Фенвика и дерево отрезков.
- `main.py`: примеры всех заданий и выбор задания по номеру.

В файлах код без комментариев. В отчёте тот же код разобран построчно. Общие функции приведены полностью при первом использовании; последующие задания ссылаются на этот разбор.

## Что показать на защите

1. Задания 3–6: поиск с количеством посещений, три обхода, три случая удаления и отличие высот 2 и 6.
2. Задание 7: четыре поворота; после каждого корень 20, потомки 10 и 30.
3. Задания 8–9: одинаковые 100000 чисел и 1000 запросов, раздельное время построения и запросов, совпадение всех ответов.
4. Задание 10: `i & -i`, перевод индекса с нуля на единицу, прибавление `delta`.
5. Задания 11–12: листья с позиции `S`, запрос суммы, минимума и максимума, замена значения.
6. Задание 13: поиск датчика 8 и отсутствие 999; изменение измерения 125 с 25 на 200; правильные запросы после изменения.

Задание 13 — готовая демонстрация. Консольного меню нет. Для другого учебного примера можно поменять исходные значения и диапазоны в функции `task13`.

## Важные правила

- Все внешние индексы начинаются с 0. Диапазон `[left, right]` включает обе границы.
- Высота дерева измеряется рёбрами: лист имеет высоту 0, пустое дерево — -1.
- В BST повторный ключ не добавляется второй раз.
- `FenwickTree.update(index, delta)` прибавляет разницу. Для замены 25 на 200 надо передать 175.
- `SegmentTree.update(index, value)` принимает новое значение. Для той же замены надо передать 200.
- Исходный список и вспомогательные структуры обновляются отдельно, как показано в коде.
- Seed 42 сохраняет данные и диапазоны в замерах. Время зависит от компьютера и текущей нагрузки.
- Красно-чёрное дерево, B-Tree и B+Tree рассмотрены в теории и ответах. Их реализация в практических заданиях не требуется.

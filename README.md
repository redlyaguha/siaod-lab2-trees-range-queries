## Запуск

Требуется Python 3.10 или новее. Установка дополнительных библиотек не нужна.

```bash
cd tree_range_lab
python main.py
```

Отдельное задание, например анализ датчиков:

```bash
python main.py 13
```

Доступны задания 1–13. В Windows при отсутствии команды `python` можно использовать `py`.

## Проверки и правила

Все внешние индексы начинаются с 0; обе границы диапазона включаются. Высота дерева измеряется рёбрами, высота пустого дерева равна −1. Повторные ключи BST не добавляются. Фенвик прибавляет `delta`, дерево отрезков принимает новое значение.

Пройдены 5577 проверок: обходы, три случая удаления, четыре поворота, все диапазоны нескольких небольших массивов, границы, отрицательные значения и повторные обновления. Код отчёта сверен с исходниками, просмотрены все страницы PDF. В опыте на 100000 элементах и 1000 диапазонах совпали все ответы обычного цикла и префиксного метода.

Seed 42 фиксирует исходные данные и диапазоны; время зависит от компьютера и нагрузки. Задание 13 — готовая демонстрация с 1000 измерениями выбранного датчика, без консольного меню.

# tree_range_lab

СиАОД, лабораторная работа 2 «Деревья и быстрые запросы к данным». Выполнены задания 1–13.

Требуется Python 3.10 или новее. Используется только стандартная библиотека.

Из этой папки запустите все задания:

```powershell
python main.py
```

Отдельное задание:

```powershell
python main.py 13
```

`bst.py` содержит операции с BST и повороты. `ranges.py` содержит структуры для диапазонных запросов. `main.py` содержит демонстрации и выбор задания.

Все диапазоны включают обе границы, индексы начинаются с 0. В задании 13 используется готовая демонстрация с 1000 измерениями датчика 8. Построчные комментарии, результаты и объяснения находятся в отчёте в родительской папке. Подробный порядок запуска — в `Инструкция.md`.
